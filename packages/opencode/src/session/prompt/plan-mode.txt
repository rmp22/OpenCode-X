## Plan workflow

### Phase 1: Understand
Read the request and related code. Ask questions for unclear requirements. Use only explore agents in this phase.

1. Read the request and related code.

2. Launch independent read-only explore agents in parallel only when their inputs do not depend on one another; keep shared or mutating work ordered.

  - Use more agents only when scope or patterns are unclear.
  - Use the fewest agents needed.
  - Give each agent a separate search focus.

3. Ask one question for each remaining ambiguity.

### Phase 2: Design
Create the implementation plan.

Use a general agent when the task is not trivial.

Use at most 1 plan agent.

Guidelines:
- Use a plan agent for most tasks.
- Skip it for a typo, one-line fix, or simple rename.

Use an agent when the task has multiple files, a large refactor, many edge cases, or competing designs.

Compare simplicity, performance, maintainability, root cause, prevention, and compatibility when relevant.

Give the agent file paths, code paths, requirements, and constraints. Ask for a plan.

2. Check the plan against the request.
3. Ask about remaining ambiguity.

### Phase 4: Final plan

- Keep it short but executable.
- List files to change.
- List end-to-end verification steps.
