Extract the text transcript from an HTTPS YouTube video.

Use this for human design guides, practitioner critiques, anti-AI-slop discussions, and LLM research videos when a transcript is available. Treat auto-captions as source material to inspect, not proof. Record the video URL and date, separate evidence from opinion, and compare claims with primary research. The tool uses the requested subtitle language, defaults to en, removes subtitle timing and markup, and returns deduplicated plain text. It requires Python 3, yt-dlp, and ffmpeg on the user's PATH.
