## Rules
- Read the manifest and nearby source before importing a package or API.
- Match the actual signature, error behavior, and lifecycle of the called boundary.
- Keep public names and schemas stable unless the request explicitly permits a break.
- Validate unknown input before narrowing it into domain logic.
- Remove guessed dependencies, wrappers, aliases, and dead references before delivery.

## Example
Before adding an import, locate the installed package, read its existing call sites, and run the narrowest type or behavior check.
