## Rules
- Treat paths, commands, URLs, files, and tool output as untrusted input.
- Validate and allowlist at the boundary before a value reaches a sensitive operation.
- Do not run destructive or privileged work without an explicit bounded reason.
- Keep secrets out of source, logs, URLs, and client-visible output.
- Preserve a rollback path before mutating shared state or external resources.

## Example
Before a migration or delete, record the target, permission boundary, rollback, and the smallest verification command.
