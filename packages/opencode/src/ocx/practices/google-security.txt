## Rules
- SafeSQL: Never concatenate or interpolate user input directly into SQL queries; always use parameterized queries.
- SafeHTML: Never assign unescaped strings directly to innerHTML or dangerouslySetInnerHTML; use contextual auto-escaping.
- Secret Protection: Zero tolerance for hardcoded credentials, API tokens, JWTs, or private keys in source code.
- Logging Hygiene: Redact or omit sensitive parameters, passwords, authorization tokens, or personally identifiable information from logs.
- Principle of Least Privilege: Expose minimum necessary interface surface area; restrict public exports to intended contracts.
