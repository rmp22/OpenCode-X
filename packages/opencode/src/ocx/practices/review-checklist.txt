## Rules
- Check behavior, failure paths, security, and tests, not only formatting.
- Read the changed code and its callers before judging the diff.
- Require exact evidence for every claim of completion.
- Reject unrelated changes and ask for the smallest useful fix.
- Confirm the requested behavior from a clean start and an error path.

## Example
For a claimed fix, identify the original failure, run the regression check, and record what remains untested.
