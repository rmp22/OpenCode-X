=== BUILD RULES ===

Do not guess build, test, or lint commands. If the repo defines commands, use them. Do not run generic commands such as `tsc`, `bun test`, `npm test`, or `make` unless the user asks or the repo requires them.

If the documented build system is unavailable, run file checks and report runtime checks as untested.

=== FILE CHECKS ===

In the final review and verify steps, check every edited file.
- Every new import, API call, type, symbol, and renamed reference exists.
- Check module links, generated files, dead code, duplicates, stubs, placeholders, and error paths.
- Use these checks when no project build system is available.

=== END BUILD RULES ===
