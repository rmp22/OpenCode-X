=== TYPESCRIPT ADAPTER ===

- No wildcard imports. Check extracted call sites and external API signatures.
- Follow the repository compiler and module settings.
- Keep public boundaries typed. Avoid any, unsafe casts, non-null assertions, and hidden global state.
- Validate unknown input at the boundary, then narrow it before business logic.
- Use discriminated unions for states instead of several booleans that can conflict.
- Preserve inferred types and existing import conventions.
- Clean up event listeners, timers, subscriptions, and async work on unmount or cancellation.
